<AccordionGroup>
  <Accordion title="How soon do I see results?">
    Your first data arrives with your first monitoring run, which starts after you finish setup. AI answers vary day to day, so give it two to three weekly runs before drawing conclusions. Watch the trend, not any single answer.
  </Accordion>
  <Accordion title="Why did my score drop?">
    Three common causes. First, AI answers naturally vary between runs. Second, if you added prompts or platforms, the mix changed: new questions you score low on pull the average down even if nothing got worse. Third, a competitor gained ground. Check the platform and topic breakdowns to see which one happened, and compare like for like before worrying.
  </Accordion>
  <Accordion title="Why does AI recommend a competitor instead of me?">
    AI assistants recommend what their sources support. If a competitor's pages, reviews, and third-party coverage answer the question better than yours, AI picks them. Competitive analysis shows exactly where and why they win, and Opportunities turns that into a fix list.
  </Accordion>
  <Accordion title="Do I need to change my website?">
    Not always. Content gaps are more common than technical ones. Run the Agent readiness scan first: it tells you in minutes whether AI crawlers can read your site at all, before you spend on bigger changes.
  </Accordion>
  <Accordion title="What is a run?">
    One run is one prompt asked once on one AI platform. Tracking 20 questions on 5 platforms costs 100 runs per cycle. Your plan includes a monthly run allowance, overage is $0.01 per run, and run packs raise your allowance.
  </Accordion>
  <Accordion title="Can I track multiple locations?">
    Yes. Create one project per location, all under one organization sharing one run pool. If your locations live in subfolders of one domain, a project can track a single subfolder like `example.com/locations/austin`. The cross-location report compares all of them side by side.
  </Accordion>
  <Accordion title="Which AI platforms are covered?">
    Seven: ChatGPT, Gemini, Perplexity, Microsoft Copilot, Grok, Google AI Overview, and Google AI Mode. Google search results are tracked alongside them through SERP Radar.
  </Accordion>
  <Accordion title="Can I export reports?">
    Yes. The Overview page exports a PDF report for any date range, and project and prompt lists export to CSV. Exports require a paid plan. The Ads page also has a shareable public link for its report.
  </Accordion>
  <Accordion title="How is this different from SEO tools?">
    SEO tools track where you rank in a list of links. Visibility Suite tracks what AI assistants actually say: whether they name you, cite your pages, and recommend you, with the full answers saved as evidence. SERP Radar bridges both worlds, showing Google rankings and AI citations together.
  </Accordion>
  <Accordion title="Does it post to my site automatically?">
    No. Content Studio drafts and refines articles, and MCP publishing can send them to your CMS, but every publish is an action you take on a draft you have reviewed. Nothing goes live on its own.
  </Accordion>
  <Accordion title="What happens if I hit my run limit?">
    On paid plans, extra runs bill at $0.01 each, so monitoring continues without interruption. Add a run pack if you expect to need more every month. Settings shows your usage and a forecast so the overage never surprises you. On the Free plan, monitoring requires an upgrade.
  </Accordion>
  <Accordion title="How often does monitoring run?">
    Weekly by default. You can change the schedule to daily, every two days, or twice weekly, and pick the day and time, in project settings. A Run now button triggers a manual run once your project is active.
  </Accordion>
  <Accordion title="Is there an API?">
    Yes, on paid plans. The API exposes the same data the app uses. See the API reference for endpoints and authentication.
  </Accordion>
</AccordionGroup>
